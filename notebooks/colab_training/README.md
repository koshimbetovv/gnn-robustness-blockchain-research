# Colab notebooks for multi-seed training
These notebooks were generated from the uploaded repo structure.
Each notebook:
- mounts Google Drive
- links `data/` to `MyDrive/data`
- runs 5 seeds
- saves per-seed run artifacts under `models/`
- saves seed summaries under `results/seed_summaries/<trainer>_5seeds/`
